# Test Case ของ Ayothaya Survival

ใช้รหัสในไฟล์นี้เพื่อสั่งทดสอบซ้ำ เช่น **“รัน TC-AUTO-02 และ TC-ITEM-03 แล้วรายงานผลจริง”** หรือ **“ทดสอบ TC-UI ทั้งหมดใน Chrome พร้อมภาพกรณีที่ไม่ผ่าน”**

## วิธีรัน

เปิดเทอร์มินัลที่โฟลเดอร์เกม แล้วใช้ Node.js รันชุดอัตโนมัติในหน่วยความจำ

~~~powershell
node --test tests/game.test.cjs
node --test --test-name-pattern=TC-AUTO tests/game.test.cjs
node --test --test-name-pattern='TC-AUTO-02|TC-ITEM-03' tests/game.test.cjs
node --test --test-name-pattern='TC-MOVE|TC-MOB|TC-COMBAT-02' tests/game.test.cjs
~~~

กรณี **Chrome** ให้รัน `node server.mjs` แล้วเปิดเกมจาก `http://127.0.0.1:4173/` ในโปรไฟล์ทดสอบแยก เริ่มจากเซฟใหม่สำหรับเควสต์แรก และใช้สำเนาเซฟที่มีเลเวล สกิล หรือไอเทมตามเงื่อนไขสำหรับกรณีเฉพาะ ใช้โปรไฟล์แยกสองชุดสำหรับ LAN และใช้โหมดจำลองการสัมผัสสำหรับกรณีมือถือ

บันทึกผลด้วย `PASS`, `FAIL` หรือ `BLOCKED` พร้อมผลที่เห็นจริง เมื่อพบปัญหาให้ระบุพิกัดหรือสถานะเซฟก่อนเกิดอาการ ขั้นตอนที่กด และภาพหน้าจอถ้ามี

## บันทึกการทดสอบรอบก่อน

ชุดอัตโนมัติผ่าน **35/35** กรณี

- **TC-TRAIN-01 — ผ่าน** คลิกวาร์ปหน้าโบราณสถานฝั่งซ้ายจากตัวละครใหม่ เข้าไปพบหุ่นนิ่งทั้งสามตัว ตัวละ 999,999 HP การโจมตีลด HP และเมื่อ HP หมดหุ่นฟื้นทันทีโดยไม่มีรางวัล วาร์ปออกกลับมาหน้าทางเข้าลานฝึก
- **TC-TRAIN-02 — ผ่าน** ใน Chrome สกิลฟันหนักรอคูลดาวน์ตามปกติ พอสลับเป็นปิดสามารถฟันต่อเนื่องและยังใช้มานา ค่าเปิด/ปิดอยู่หลังโหลดหน้าใหม่และปุ่มใช้ได้ที่ความกว้าง 390 พิกเซล การต่อสู้นอกลานฝึกใช้คูลดาวน์ตามปกติ เซิร์ฟเวอร์ LAN รับตำแหน่งในลานฝึกสำเร็จ
- **TC-TRAIN-03 — ผ่าน** ใน Chrome ฟันหนักได้ที่ 0 MP หลังปิดสวิตช์ คูลดาวน์ยังเปิดอยู่ ค่าคงอยู่หลังโหลดหน้าใหม่ ปุ่มแสดงครบที่ความกว้าง 390 พิกเซล และกลับหมู่บ้านแล้วสกิลใช้มานาตามปกติ ชุดอัตโนมัติยืนยันด้วยว่า Auto ใช้สกิลได้และเก็บน้ำอบไว้
- **TC-TRAIN-04 — ผ่าน** ใน Chrome แถบ HP กลับเป็น 999,999 หลังรับดาเมจประมาณ 5 วินาที ชุดอัตโนมัติยืนยันว่าการตีซ้ำเริ่มนับใหม่เฉพาะหุ่นที่โดน
- **TC-TRAIN-05 — ผ่าน** ใน Chrome พิกัดต่างกัน 30 และ 40 หน่วย แสดงระยะเส้นตรง 50.0 หน่วย ระยะอัปเดตเมื่อเดินและคงเดิมเมื่อซูม ตัวเลขอยู่ในแถบเป้าหมายที่ความกว้าง 390 พิกเซล และระยะสกิลโจมตีครบทั้งห้าท่าในหน้าสกิล
- **TC-COMBAT-02 — ผ่าน** หลังปรับฟันหนัก ใน Chrome ใช้สกิลที่ระยะ 90 หน่วย หุ่นได้รับดาเมจ มีเอฟเฟกต์ตรงจุดปะทะ และใช้มานา 5 ที่ระยะ 91 หน่วย เกมแจ้งว่าอยู่นอกระยะสกิล
- **TC-COMBAT-01 — ผ่าน** ชุดทดสอบยืนยันว่าเริ่มโจมตีหุ่นได้จากจุดเดิมที่ระยะ 100 หน่วย และเดินเข้าหาก่อนเมื่อเริ่มที่ระยะ 101 หน่วย
- **พุ่งแทงใจ — ผ่าน** ใน Chrome พุ่งผ่านหุ่นไป 30 หน่วยทั้งสองทิศ ดาเมจและประกายขึ้นที่หุ่น ชุดทดสอบยืนยันว่าถ้ามีกำแพงหลังเป้า ตัวละครหยุดก่อนกำแพงและยังทำดาเมจได้
- **แทงใจดำ — ผ่าน** ใน Chrome แทงได้ทั้งซ้ายและขวาจากตำแหน่งเดิม เมื่อแทงโดน แถบเป้าหมายขึ้นสถานะเลือดไหลและหุ่นรับดาเมจต่อเนื่องครบสามครั้ง ชุดทดสอบยืนยันว่าการแทงซ้ำเริ่มนับเวลาใหม่ และให้รางวัลครั้งเดียวเมื่อเลือดไหลกำจัดเป้าหมาย
- **ฟันสกัด — ผ่าน** เปิดและจัดสกิลผ่านสมุดสกิลใน Chrome แล้วลองกดช่องลัดและเปิด Auto ในลานฝึก ทั้งสองวิธีแสดงรอยฟันไขว้ ตัวเลขคริติคอลลอยเหนือรอยฟัน
- **กันภัย — ผ่านใน Chrome** โล่หยกตามตำแหน่งตัวละครและหายเมื่อครบเวลา ประกายขึ้นทั้งซ้ายและขวาตามทิศที่โดนโจมตี จากยักษ์ศิลาในการทดสอบได้รับดาเมจ 8 ขณะใช้สกิล และ 16 หลังโล่หมดเวลา

รอบก่อนหน้าทดสอบซ้ำใน Chrome ตามสามกรณีด้านล่างและตรวจการแสดงทิศฟันผ่าน LAN ด้วยสองโปรไฟล์ในเครื่องเดียว
